# Feature Status

| Area | Feature | Status | Notes |
| :--- | :--- | :--- | :--- |
| **Core Focus** | Single Session Timer (`Pomodoro`, `Deep Work`, `Custom`, `Short/Long Break`) | Implemented & Tested | Monotonic elapsed realtime tracking, reboot interruption guard, 1s UI ticker, completion retry card, synchronous start guard against double taps, and conditional timer clearing so a duplicate completion cannot delete a newer timer. |
| **Core Focus** | Pomodoro Chain Mode | Implemented & Tested | Configurable sessions (1–8), focus/short/long break durations, long-break cadence, manual vs auto-transition. Chain advance is exactly-once (`lastAdvancedSessionId`) and atomically persisted with the next timer (`pendingStepSessionId`), so worker completion, process death, and cold start share one pure `ChainStateMachine` recovery path. Recovery refuses to attach an unrelated timer, parks mismatched chains for explicit user action, and schedules recovered steps for their remaining time. |
| **Audio** | Procedural Ambient Soundscapes | Implemented & Tested | Pure offline `AudioTrack` PCM synthesizer (`Soft Rain`, `Forest Wind`, `Ocean Waves`, `Hearth Ember`, `Deep Focus Hum`), live volume, optional timer sync, audio-focus request/loss handling, becoming-noisy pause, foreground-only lifecycle, guarded track state/writes, cancellation propagation, and guaranteed release in `finally`. Physical speaker/headphone validation pending an API 36 device. |
| **Usage Insights** | Android UsageStats Integration | Implemented & Tested | Explicit opt-in disclosure, typed `UsageQueryResult`, exact millisecond aggregation preserving `<1m` apps, `ZERO_USAGE` vs `UNAVAILABLE` distinction, coalesced 30s cache, 14-day historical query + Room cache, daily budget tracker, and cancellation-safe refresh that never caches a phantom error. |
| **Usage Insights** | Honest Baseline Comparisons | Implemented & Tested | Partial today never compared against completed days; compares most recent completed day vs 7 prior completed days, plus 7-day-vs-7-day weekly comparison. |
| **Core Focus** | Reusable Routines & One-Action Starts | Implemented & Tested | Named focus templates reuse the existing `ChainConfig`, `FocusTimerEngine`, and `ChainStateMachine`. Start from Today, Focus, or the Routines screen in one action. Editing or deleting a template never mutates an active timer or completed history. |
| **Core Focus** | Session Context & Categories | Implemented & Tested | Optional category, intention, note, and reflection. Completed sessions copy routine/category name and configuration snapshots; there are no foreign keys. Notes/reflections use a narrow metadata-only update and never affect XP, seeds, trees, achievements, or challenges. |
| **History** | Filterable Session History | Implemented & Tested | Bounded SQL queries with date-range, category, routine, status, and text filters; defaults to finished sessions. Session detail shows stored facts and snapshots, and allows note/reflection editing. |
| **Today** | Pinned Routines, Active Session & Weekly Goal | Implemented & Tested | Today shows pinned routine quick-starts, the active/paused session with context, recent activity, and an independently persisted weekly goal initialized once from the previous `daily × 7` intention. |
| **Analytics** | Focus Trends (`7D` / `30D` / `90D`), Peak Windows, Breakdown, Streak Calendar | Implemented & Tested | Genuine `startedAtWallMs` time-of-day buckets, monthly consistency %, month switching, interactive day detail inspection, plus category/routine breakdowns and average completed-block duration scoped to the selected window with honest sample counts. |
| **Today** | Calendar-Week Focus Intention | Implemented & Tested | Monday–Sunday focus total with an independently persisted weekly target (0 disables it). New installs initialize it once from the prior effective intention (`daily × 7`); later daily-goal edits do not rewrite it. |
| **Gamification** | Transactional `RewardAuthority` & `RewardLedger` | Implemented & Tested | Idempotent session/challenge/achievement/streak credits; breaks earn 0 XP / 0 seeds / 0 trees; custom challenge rewards capped at 3/day. XP level math uses Long arithmetic and a level ceiling to prevent overflow on extreme lifetime XP. |
| **Challenges** | Daily, Weekly & Custom Challenge CRUD | Implemented & Tested | Deterministic daily/weekly generation, custom input bounds, inline editing, deletion/archival preserving ledger auditability, usage-baseline refresh before evaluation, and local Challenge History for archived, expired, and past-period goals. |
| **Forest & Shop** | Interactive Canvas Grove & Botanical Shop | Implemented & Tested | Real tree species placement, equipped environments & decorations, Leaf Points balance, `All` / `Owned` filters, insufficient points feedback. |
| **Notifications** | Background Workers (`SessionCompletion`, `FocusReminder`, `WeeklySummary`) | Implemented & Tested | Stale ID guards, quiet hours enforcement, channel setup, central WorkManager cancel/sync, and cancellation-aware completion workers. Physical Doze validation pending real-device run. |
| **Accessibility** | Screen-Reader Timer Semantics | Implemented & Tested | The focus countdown exposes explicit spoken units (for example “24 minutes 12 seconds remaining, paused”) without a per-second live region. Routine/category chips and history filters carry labels and test tags; full TalkBack/font-scale device pass remains pending. |
| **Data & Privacy** | Room v3 + `MIGRATION_1_2` / `MIGRATION_2_3` + Privacy Controls + CSV Export + Full Wipe | Implemented & Tested | Verified `1 -> 2`, `2 -> 3`, and `1 -> 3` migrations preserving rows and rewards. Routine/category tables, session-context columns, and weekly goal are local-only. `allowBackup="false"`, zero network, atomic `deleteAllLocalData` clears the new tables and preferences; only documented starter templates may be re-seeded after onboarding. |
| **Monetization** | Play Billing / Optional Cosmetic Packs | Scaffolded (`LocalFreeEntitlementGateway`) | Honest local-free entitlement abstraction with zero fake purchases or local unlock flags; Play Billing integration intentionally deferred for future release phase. |
